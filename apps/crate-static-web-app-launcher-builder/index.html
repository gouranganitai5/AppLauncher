What you're building
One repository → one animated launcher → many independent static apps. Add your existing HTML apps in the Applications tab, each one keeps its own files, CSS and JavaScript untouched. When you build, every app's entry file becomes index.html inside its own folder, and the launcher on top links out to each of them by relative path — so it works unmodified on GitHub Pages, Netlify, or any static host.
